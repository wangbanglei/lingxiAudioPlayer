# 聆息音乐播放器

聆息是一个纯前端的本地音乐播放器，单文件即可运行，无需安装、无需联网。配套提供咪咕歌单批量下载脚本，可一键拉取 MP3、LRC 歌词与封面，拖入播放器即可收听。

---

## 一、播放器

### 简介

`index.html` 是聆息的主程序，双击或用浏览器打开即可使用。支持 MP4 / MP3 播放、LRC 字幕同步、播放进度记忆与媒体库持久化。

### 功能介绍

#### 媒体管理

- 支持添加 **MP4、MP3** 音视频文件
- 支持导入 **LRC 字幕**（按文件名自动匹配同名媒体）
- 支持导入 **封面图片**（jpg / png / webp 等，按文件名自动匹配同名媒体）
- 拖拽文件到左侧目录，或点击「添加」按钮选择文件
- 列表显示文件大小、时长、上次播放位置、已播完状态、字幕标记
- 三种排序方式：默认（添加顺序）、名称升序、名称降序
- 侧边栏宽度可拖拽调整（180–600px），刷新后保持

#### 播放控制

- 自定义播放界面：进度条、播放/暂停、±10 秒、上一曲/下一曲
- 音量调节与静音
- 播放倍速：0.5x ~ 2x
- 音频显示波形动画，视频按 16:9 比例展示
- LRC 字幕实时滚动同步
- 可选「播放结束后自动下一首」

#### 数据持久化

- **IndexedDB** 保存媒体文件，刷新页面后文件仍在
- **localStorage** 记录：
  - 每个文件的播放进度
  - 已播完标记
  - 当前选中文件、排序方式、音量、倍速、侧边栏宽度等

### 使用方法

1. 用浏览器直接打开 `index.html`
2. 将 MP4 / MP3 / LRC / 封面图片拖入左侧「媒体目录」，或点击添加按钮选择文件
3. 在列表中点击文件开始播放
4. 使用底部控制栏或快捷键操作播放

> 列表为空时，点击空白区域可快速打开文件选择器；已有文件时请点击「添加」按钮。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放 / 暂停 |
| `←` | 后退 10 秒 |
| `→` | 前进 10 秒 |
| `PageUp` | 上一曲 |
| `PageDown` | 下一曲 |

鼠标悬停在操作按钮上可查看对应提示。

### 设计说明

- **单文件架构**：所有逻辑、样式、资源内嵌于 `index.html`，部署简单，双击即用
- **本地优先**：文件与播放数据均保存在浏览器本地，不上传服务器
- **深色主题**：适配长时间观看/收听场景
- **渐进增强**：空列表引导、播放状态反馈、列表元信息一目了然

### 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- IndexedDB（媒体文件存储）
- localStorage（用户偏好与播放状态）
- File API / Blob URL（本地文件读取与播放）

### 浏览器兼容

建议使用现代浏览器（Chrome、Edge、Firefox 等）。需支持 IndexedDB 与 HTML5 音视频播放。

## 二、咪咕歌单下载脚本

### 简介

`download-migu-playlist.js` 是一个 **Node.js 命令行工具**，用于从咪咕音乐批量下载歌单中的歌曲，并自动生成与聆息播放器配套的文件：

- **MP3 音频**（优先 320k 音质）
- **LRC 歌词**（同名匹配，导入后自动显示字幕）
- **封面图片**（jpg / png / webp，同名匹配，导入后显示缩略图）

下载完成后，将整个歌单文件夹拖入聆息左侧「媒体目录」即可播放。

### 环境要求

- [Node.js](https://nodejs.org/) 18 及以上（需支持原生 `fetch`）

### 使用方法

在终端进入项目目录（或任意希望保存歌单的目录），执行：

```bash
# 方式一：直接传入歌单 ID
node download-migu-playlist.js 235890246

# 方式二：使用参数
node download-migu-playlist.js --playlistId 235890246

# 指定歌单类型（默认为 create）
node download-migu-playlist.js -p 235890246 --playlistType create
```

**歌单 ID 获取方式**：打开咪咕音乐歌单页面，URL 中的 `playlistId` 即为所需 ID，例如：

```
https://music.migu.cn/v5/#/playlist?playlistId=235890246&playlistType=create
                                                      ^^^^^^^^^
```

### 保存规则

脚本会在**当前工作目录**下自动创建 `audio` 文件夹（已存在则直接使用），并在其中创建以歌单名命名的子文件夹，每首歌保存为三个同名文件：

```
audio/
└── 歌单名/
    ├── 歌曲名-歌手名.mp3
    ├── 歌曲名-歌手名.lrc
    └── 歌曲名-歌手名.jpg
```

### 其他说明

- 自动翻页加载歌单中的全部歌曲
- 本地已存在的完整文件（音频、歌词、封面）会自动跳过，适合断点续下
- 按 `Ctrl+C` 取消时，会删除当前未下载完成的临时文件
- 部分歌曲可能因版权限制无法获取下载链接，脚本会跳过并继续下一首

> 本脚本仅供个人学习与研究使用，请遵守相关法律法规及平台服务条款。
